## 🔓 Open-Source GitHub Projects 🛠️

*Sorted by GitHub Stars Count (Descending)* 🌟

- **[Traccar](https://github.com/traccar/traccar)** [![Stars](https://img.shields.io/github/stars/traccar/traccar?style=social&color=white)](https://github.com/traccar/traccar/stargazers) 🌟  
  **The leading open-source GPS tracking system**, Apache-2.0 licensed. **Supports 200+ GPS protocols** and thousands of device models (Teltonika, Concox, Queclink). Real-time map tracking, geofencing, driver identification, fuel monitoring, and customizable push/email/SMS notifications. Modern web interface (React) and REST API. Enterprise-proven for tracking millions of assets. 🗺️

- **[Open Vehicle Monitoring System 3 (OVMS)](https://github.com/openvehicles/Open-Vehicle-Monitoring-System-3)** [![Stars](https://img.shields.io/github/stars/openvehicles/Open-Vehicle-Monitoring-System-3?style=social&color=white)](https://github.com/openvehicles/Open-Vehicle-Monitoring-System-3/stargazers) 🌟  
  **Comprehensive open-source EV and vehicle telematics platform**, Apache-2.0 licensed. **Native support for 35+ electric vehicle models** (Tesla Model S, Nissan Leaf, BMW i3, Hyundai Ioniq 5, VW e-Golf). Hardware based on ESP32 with 3x CAN buses, WiFi, Bluetooth, and 4G cellular modem. Live data extraction via DBC files, OBD-II, and CAN frames with MQTT server streaming. 🚗

- **[Routario](https://github.com/bkbilly/Routario)** [![Stars](https://img.shields.io/github/stars/bkbilly/Routario?style=social&color=white)](https://github.com/bkbilly/Routario/stargazers) 🌟  
  **Self-hosted GPS fleet tracking & analytics platform**, open-source. **100% data privacy with no external cloud subscriptions**. Direct TCP/UDP packet parsing for popular GPS hardware (Teltonika, Queclink, TK103). Features live interactive maps, geofence rules, speed violations, trip history playback, and multi-channel alerting (Telegram, Discord, Slack). Built with Python (FastAPI) & Vanilla JS. 🛰️

- **[Nexus SDV](https://github.com/googlecloudplatform/nexus-sdv)** [![Stars](https://img.shields.io/github/stars/googlecloudplatform/nexus-sdv?style=social&color=white)](https://github.com/googlecloudplatform/nexus-sdv/stargazers) 🌟  
  **Google Cloud's Software-Defined Vehicle reference architecture**, Apache-2.0 licensed. **Android Automotive OS VHAL integration** for vehicle telemetry collection. High-throughput telemetry ingestion powered by NATS messaging and Google Cloud BigTable. Features PKI security, Digital Twin Virtual ECUs, and automated Terraform infrastructure deployment. ☁️

- **[Eclipse Connected Services Platform (ECSP)](https://github.com/eclipse-ecsp/ecsp)** [![Stars](https://img.shields.io/github/stars/eclipse-ecsp/ecsp?style=social&color=white)](https://github.com/eclipse-ecsp/ecsp/stargazers) 🌟  
  **Harman's open-sourced connected vehicle cloud platform**, Eclipse Foundation project. **Scales to 100,000+ connected vehicles**. Complete architecture including C++ vehicle edge clients, MQTT connectivity, Apache Kafka stream ingestion, microservices backends, and mobile client SDKs. Deployed on Kubernetes with ArgoCD workflows. 🏗️

- **[ITS Telematics (USDOT)](https://github.com/usdot-fhwa-stol/its-telematics)** [![Stars](https://img.shields.io/github/stars/usdot-fhwa-stol/its-telematics?style=social&color=white)](https://github.com/usdot-fhwa-stol/its-telematics/stargazers) 🌟  
  **USDOT's open-source vehicle telematics module**, Apache-2.0 licensed. Designed for **Cooperative Driving Automation (CDA) research**. Plugs into research testbeds (CARMA Platform) and production vehicles for real-time sensor data streaming, vehicle dynamics logging, and visualization via CARMA Cloud. 🏛️

- **[telemetry-obd](https://github.com/thatlarrypearson/telemetry-obd)** [![Stars](https://img.shields.io/github/stars/thatlarrypearson/telemetry-obd?style=social&color=white)](https://github.com/thatlarrypearson/telemetry-obd/stargazers) 🌟  
  **Optimized OBD-II data logger for Raspberry Pi & Linux edge hardware**, open-source. Categorizes PIDs into Startup, Housekeeping, and fast Cycle loops (RPM, Throttle, MAF). Outputs structured ISO-timestamped JSON records with automatic handling of intermittently unsupported vehicle commands. 📝

- **[obd-tui](https://github.com/goabonga/obd-tui)** [![Stars](https://img.shields.io/github/stars/goabonga/obd-tui?style=social&color=white)](https://github.com/goabonga/obd-tui/stargazers) 🌟  
  **Terminal UI dashboard for ELM327 OBD-II adapters**, MIT licensed. Built with Python Textual. Auto-discovers vehicle PIDs and presents tabbed views for Engine performance, Turbo/Airflow, Fuel Economy, and Fault Codes (DTC). Features real-time rolling charts and `--demo` simulation mode. 🖥️

- **[obd_project](https://github.com/AlexLangan/obd_project)** [![Stars](https://img.shields.io/github/stars/AlexLangan/obd_project?style=social&color=white)](https://github.com/AlexLangan/obd_project/stargazers) 🌟  
  **Python OBD-II data logger with automatic PID discovery**, open-source. Captures engine RPM, speed, throttle position, engine load, coolant temp, and fuel rate to CSV files. Includes PID scanner tools and containerized Docker execution. 🐍

- **[CAN-DAQ](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection)** [![Stars](https://img.shields.io/github/stars/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection?style=social&color=white)](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection/stargazers) 🌟  
  **Open-source hardware + software CAN bus data acquisition system**, open-source. ESP32-S3 hardware interface paired with a Python GUI. Real-time DBC signal parsing, live signal plotting (Matplotlib), and high-frequency SQLite data logging. 📊

- **[Fleet Management System](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection)** [![Stars](https://img.shields.io/github/stars/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection?style=social&color=white)](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection/stargazers) 🌟  
  **Comprehensive Python telematics framework**, open-source. Decodes multi-protocol OBD-II (ISO 15765 CAN, J1850), NMEA GPS feeds, and DBC CAN bus data. Includes a database of 600+ Diagnostic Trouble Codes (DTC), severity scoring, and threshold alert triggers. 🔧

- **[CAN Logger](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection)** [![Stars](https://img.shields.io/github/stars/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection?style=social&color=white)](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection/stargazers) 🌟  
  **Lightweight CAN and CAN-FD frame logger**, open-source. Captures raw CAN interface (`vcan0`, `can0`) traffic into SQLite databases with filtering tools by arbitration ID, timestamps, and payload length. 📡

- **[pycangui](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection)** [![Stars](https://img.shields.io/github/stars/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection?style=social&color=white)](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection/stargazers) 🌟  
  **Graphical CAN bus analyzer and diagnostic tool**, Apache-2.0 licensed. Multi-protocol support covering CANopen, UDS (ISO-TP), J1939, and XCP/CCP. DBC message editor, signal graphing, and hot-reloadable Python analytical scripts. 🎛️

- **[OpenGTS](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection)** [![Stars](https://img.shields.io/github/stars/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection?style=social&color=white)](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection/stargazers) 🌟  
  **Open GPS Tracking System**, Apache-2.0 licensed. Classic Java-based telematics platform for tracking commercial vehicle fleets. Features device-independent protocols, web interface reporting, and geofence triggering. 📍

- **[SDV Telemetry (Android Automotive)](https://source.android.google.cn/docs/automotive/sdv/workstreams/telemetry)** [![Stars](https://img.shields.io/github/stars/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection?style=social&color=white)](https://github.com/ishandutta2007/Awesome-Automotive-Fleet-Data-Collection/stargazers) 🌟  
  **Android's official vehicle telemetry engine**, open-source. Written in Rust for memory safety. Supports cloud-configured Telemetry Campaigns, edge data reduction, and direct VHAL integration on Android Automotive OS. 🤖

## ⚠️ Disclaimer 🚨

- This is a **community-curated** list — not exhaustive and not an endorsement. ℹ️
- Vehicle data collection raises significant privacy and security concerns. **Review data ownership, consent requirements, and regulatory compliance** (GDPR, CCPA, automotive cybersecurity standards) before deploying any telematics solution. Open-source tools like OVMS and Routario provide self-hosted ownership, but commercial platforms offer managed SLAs and 24/7 support.
- CAN bus access requires proper training. **Incorrect bus connections or bitrate mismatches can disrupt vehicle networks** and potentially affect safety-critical systems. Always follow manufacturer guidelines and use appropriate hardware isolation. 🚗
